## Snake Game 

Changes we've made:

### Visual & UI Enhancements
- **Background:** Updated to a light purple color with white text for a modern, clean look.  
- **Canvas Glow:** Added a glowing border around the game canvas for a dynamic effect.  
- **Enhanced Screens:** Game menu, settings, and game-over screens now feature gradients, glow effects, and improved layout for a smoother user experience.

### 🐍 Snake & Food Upgrades
- **Snake Emoji:** The snake’s segments are now displayed as snake emojis instead of plain squares.  
- **Fruit Food:** Food is now randomly generated fruit emojis 🍎🍌🍉🍇🍒🍓🍍🥭, making the game more colorful and fun to play.

### ameplay Features
- **High Score Tracking:** Your high score is displayed and automatically saved using local storage.  
- **Controls:** Added WASD keys alongside arrow keys, giving players flexible movement options.
