## Essential Terminal Commands You Need to Know

Before diving into setup, let's master the basic shell commands that you'll use every day. 

### Navigation and File Management

```bash
ls          # list files and folders in current directory
ls -la      # list all files (including hidden) with detailed info
pwd         # show current directory path (Print Working Directory)
mkdir       # create new folders
cd          # navigate between directories
cd ..       # go up one directory level
cd ~        # go to your home directory
```

### Reading and Editing Files

```bash
cat filename.txt     # read file content in terminal
less filename.txt    # read file content with scrolling (press 'q' to exit)
nano filename.txt    # edit file in terminal (Ctrl+X to exit)
touch filename.txt   # create empty file
rm filename.txt      # delete file (be careful!)
rm -rf foldername    # delete folder and everything inside (very careful!)
```

### Practical Examples

```bash
# Create a project structure
mkdir my-project
cd my-project
mkdir src tests docs
ls                   # You'll see: src  tests  docs

# Navigate and check where you are
cd src
pwd                  # Shows: /Users/yourname/my-project/src
cd ..                # Back to my-project
```

## Version Control with Git

Git is essential for any developer. Here are the core commands that will handle 90% of your needs:

### Basic Git Workflow

```bash
git clone <repository-url>    # copy a repo from GitHub to your machine
git status                    # see what files have changed
git add .                     # stage all changes for commit
git add filename.txt          # stage specific file
git commit -m "Your message"  # save changes locally with descriptive message
git push                      # send local changes to GitHub
git pull                      # update local copy with remote changes
```

### Checking Your Git Setup

```bash
git config --global --list    # see your current git configuration
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

### Real-World Git Example

```bash
# After making changes to your code
git status                           # See what changed
git add .                           # Stage everything
git commit -m "Add new feature"     # Commit with clear message
git push                            # Send to GitHub
```

## Package Management with Homebrew

Homebrew is the missing package manager for macOS. It makes installing development tools incredibly simple.

### Essential Homebrew Commands

```bash
brew list                           # see what's installed
brew search <package-name>          # find packages
brew install <package-name>         # install a package
brew uninstall <package-name>       # remove packages you don't need
brew update && brew upgrade         # keep everything fresh and up-to-date
brew doctor                         # check for potential issues
```

### Common Packages You'll Want

```bash
brew install git                    # Version control
brew install python                 # Python programming language
brew install node                   # Node.js for web development
brew install ruby                   # Ruby programming language
```

## Health Checks: Verify Everything Works

Run these commands regularly to ensure your environment is healthy:

### System Check Commands

```bash
# Programming languages
python3 --version        # Should show Python 3.x
pip3 --version          # Should show pip version
ruby -v                 # Should show Ruby version
node --version          # Should show Node.js version
npm --version           # Should show npm version

# Development tools
git --version           # Should show Git version
code --version          # Should show VS Code version
brew --version          # Should show Homebrew version

# Ruby gems (if using Jekyll)
bundle -v               # Should show Bundler version
gem --version           # Should show RubyGems version

# Git configuration
git config --global --list    # Shows your Git username and email
```

### Troubleshooting Failed Health Checks

**If `python3 --version` fails:**
```bash
brew install python
# or
brew upgrade python
```

**If `git config --global --list` is empty:**
```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

**If `code --version` fails:**
```bash
# Reinstall VS Code
brew uninstall --cask visual-studio-code
brew install --cask visual-studio-code
```

## Daily Development Routine

Here's my streamlined startup routine for every coding session:

### Morning Setup (Every Day)

```bash
# Navigate to your main project
cd opencs/student

# Activate your Python virtual environment
source venv/bin/activate

# Update your code from GitHub
git pull

# Open VS Code in current directory
code .
```

**Pro tip:** You can combine these into a single command:
```bash
cd opencs/student && source venv/bin/activate && git pull && code .
```

### End-of-Day Cleanup

```bash
# Save your work
git add .
git commit -m "End of day: describe what you worked on"
git push

# Deactivate virtual environment
deactivate
```

## Advanced Tips and Shortcuts

### Terminal Shortcuts That Save Time

```bash
# Command history
↑ ↓           # Navigate through previous commands
Ctrl + R      # Search command history
Ctrl + C      # Cancel current command
Ctrl + L      # Clear screen (same as 'clear')

# Text navigation
Ctrl + A      # Jump to beginning of line
Ctrl + E      # Jump to end of line
Ctrl + W      # Delete word before cursor
```
